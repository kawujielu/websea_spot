`spot_market_maker` 是现货**三层盘口做市**工程（近盘 / 防御 / 远盘）。各脚本功能如下：

定时任务：
0 */3 * * * > /home/ubuntu/code/spot_market_maker/nohup.out

#### 现货MM spot_market_maker

服务器位置：ubuntu@10.0.208.182 ubuntu@10.0.209.47 | /home/ubuntu/code/spot_market_maker                                                                                                                                                         

启动程序：restart.sh

1. config.py

   配置当前服务允许的交易对，内网ip + server识别号

   ```
   ipMapping = {                               
           "ip-10-0-208-182-1": symbols_USDT[:50],
           "ip-10-0-209-47-1": symbols_USDT[50:],
       }            
   ```

2. manage.py

   近盘口策略、防御策略、深度策略分为三个进程。

   深度策略更新频次低，为了充分利用cpu，把部分进盘口策略放到此进程，逻辑见strategy/depth_strategy/depth_main.py

   ```
   p_near_run = Process(target=near_run)
   p_near_run.name = "near_run"
   
   p_defense_run = Process(target=defense_run)
   p_defense_run.name = "defense_run"
   
   p_depth_run = Process(target=depth_run)
   p_depth_run.name = "depth_run"
   ```

3. 做市服务里会根据对冲敞口计算价差、深度

   libs/config_update_ser.py 里的update_price_percent_via_hedge是具体的逻辑

   ```
   """
   hedge_cny:对冲缺口阈值折合人民币
   scaled_percent：买卖一价差单边偏移量百分比
   spread_percent：档位价差倍数
   amount_percent：近盘口深度倍数
   defense_amount_percent： 防御盘口深度倍数
   # 通过对冲池量矫正价差,
   如果没获取到内存中的值。获取新的值。并计算当前的对冲量适合调整价差为多少偏移量合适
   如果获取到内存中的值，判断上次更新时间和当前时间是否相差1分钟，
       如果相差大于一分钟：
           重新获取新的值
       否则：
           获取内存中的上一次的更新的加权系数
       {'BTC': {'amounts': -0.0001763570522883292,
               'amounts_as_AQ': -39.520994640990516,
                'avg_AQ_price': 108675.28403878243,
                'consequent_hedging_hours': 0.0,
                'hedged_currencies': 'BTC',
                'hedging_states': 0,
                'is_alertings': 0,
                'thresholds': -0.8924727420975108,
                'thresholds_as_AQ': -200000.0}, }
   """
   ```

### 入口
| 脚本 | 功能 |
|------|------|
| `manage.py` | 启动：三进程分别跑 near / defense / depth + 错误消息消费 |
| `restart.sh` | 杀旧进程并重启 `manage.py run SERVER=x` |
| `initialization.py` | 进程初始化（共享内存等） |
| `config.py` | 本机配置：交易对列表、API host、账户映射（依赖 abclibs） |

---

### 策略（核心）
| 脚本 | 功能 |
|------|------|
| `strategy/strategy_base.py` | 做市基类：取价、撤挂、批量下单、防自成交、闪单、循环主逻辑 |
| `strategy/strategy_base_settings.py` | 公共参数：价差、调价开关、最小量等 |
| `strategy/near_strategy/near_main.py` | 近盘进程入口（约一半交易对） |
| `strategy/near_strategy/near_base.py` | 近盘挂单：贴买卖一阶梯铺单 |
| `strategy/near_strategy/near_settings.py` | 近盘档位数、休眠、账户 |
| `strategy/defense_strategy/defense_main.py` | 防御盘进程入口 |
| `strategy/defense_strategy/defense_base.py` | 防御档挂单（中间层深度） |
| `strategy/defense_strategy/defense_settings.py` | 防御策略参数 |
| `strategy/depth_strategy/depth_main.py` | 远盘进程入口（并兼跑另一半 near） |
| `strategy/depth_strategy/depth_base.py` | 远盘/深度档挂单 |
| `strategy/depth_strategy/depth_settings.py` | 远盘策略参数 |

---

### API / 配置热更
| 脚本 | 功能 |
|------|------|
| `abcapi_plus.py` | Websea 现货下单/改单/撤单/查委托 |
| `libs/config_update_ser.py` | 热更：维护状态、价差%、刷量%、精度、对冲驱动调参 |
| `libs/adj_component.py` | 按危险等级/计价区算近·防·远调价参数 |
| `many_config/risk_control_c.py` | 对冲缺口 → 价差/深度倍数风控表 |
| `many_config/precision_config.py` | 现货精度拉取 |
| `many_config/initializer.py` / `global_variable.py` | 共享内存与全局变量 |
| `many_config/aiohttp_limits.py` | 按交易对数限制 aiohttp 并发 |
