### `monitor_spot/` 现货（README 定时）
| 脚本 | 功能 |
|------|------|
| `withdraw_exchange_async.py` | 拉取外盘充提开关，同步/对比 Websea，写库告警 |
| `withdraw_exchange_fee_async.py` | 同步各所提币手续费，对比 Websea 费率规则 |
| `exchange_symbols.py` | 同步外盘交易对，维护参考交易所表 |
| `exchange_status.py` | Selenium 抓外盘公告（维护/充提/下架等）推送 |
| `check_redis_price.py` | Redis 价格字段是否与对标配置一致 |
| `check_pair_exchange_async.py` | 可增参考所、单所关充提等对标提醒 |
| `withdraw_deposit_monitor_async.py` | Websea 与对冲所同链充提状态不一致告警 |
| `check_hedge_config.py` | 对冲交易所 vs 参考所/对标优先级不匹配告警 |
| `redis_precision.py` | Websea 现货/合约精度写入 Redis |
| `check_libs_config.py` | 远程 `abclibs` 配置重复、漏改、现货合约重复对标 |
| `record_margin_db.py` | BN/Gate 杠杆借贷与划转落库 |
| `check_hedge_exchange_fee.py` | Websea 与对冲所提币费差超阈值告警 |
| `loan_margin_borrow.py` | BN/Gate 杠杆借入余额监控推送 |
| `clear_chrom.sh` | 清理 Chrome / chromedriver 进程 |

### `monitor_spot/` 其它工具

| `abc_check_order_status.py` | 检查做市账户挂单异常状态 |
| `margin_api_bn.py` | BN 杠杆 API 调试/查询 |
| `exchange_status_old.py` | 公告监控旧版 |
