`spot_paddington` 是现货**敞口对冲 + 自动充提**项目：

服务器位置：ubuntu@10.0.209.218 | /home/ubuntu/code/spot_paddington

主要脚本：
1. 对冲 restart.sh
   对冲相关数据库：hedge
   hedge.abc_asset_gap 平台用户成交敞口数据
   hedge.external_asset_gap 对冲平台成交敞口数据
   存数据的脚本是spot_panddington/core_external/external_asset.py
   hedge.hedge_config 交易对对冲配置
   hedge.orders 对冲逐笔订单数据
   hedge.trades 成交数据

2. 数据源 restart_ws.sh
   获取订阅获取市场数据，下单时候使用

3. 对冲服务重启流程
   1. 为了保证当前在运行的订单能够在重启前全部成交或者撤单，需要执行重启下流程：在管理后台关闭对冲开关，保证 现货对冲群 确认对冲已经关闭
   2. 为了保证重启之后对冲前服务没有问题，重启之后默认对冲服务是关闭的，需要在管理后台打开对冲开关

4. 自动化提币
   重启充提币脚本：sh spot_paddington/auto_wd/restart.sh

定时任务：
0 10 */5 * * > /home/ubuntu/code/spot_paddington/nohup.out
0 16 1 * * > /home/ubuntu/code/spot_paddington/auto_wd/nohup.out
0 10 */3 * * > /home/ubuntu/code/spot_paddington/ws_nohup.out
0 * * * * cd /home/ubuntu/code/spot_paddington/auto_wd && /usr/bin/python3 monitor_bn_gate_to_196.py >> /home/ubuntu/code/spot_paddington/auto_wd/withdraw_monitor.log 2>&1

全部脚本内容：
### 入口
| 脚本 | 功能 |
|------|------|
| `launcher.py` | 主进程：对冲、缺口采集、充提费采集、Sanic、外盘订单 WS |
| `launcher_ws.py` | 深度 WS 进程：多交易所盘口进共享内存 |
| `initialization.py` | 事件循环/任务弱引用等进程初始化 |
| `restart.sh` / `restart_ws.sh` | 重启主进程 / WS 进程 |

### `engine/` 核心引擎
| 脚本 | 功能 |
|------|------|
| `position_hedge.py` | 敞口检测与外盘对冲下单 |
| `position_collector.py` | 调度内部资产 / 充提费等采集任务 |
| `initializer.py` | 引擎初始化（账户、交易所实例等） |
| `sanic_ser.py` | HTTP 服务（查询/控制） |

### `core_internal/` / `core_external/`
| 脚本 | 功能 |
|------|------|
| `abc_asset.py` | Websea 内部资产/缺口采集 |
| `external_asset.py` | 外盘资产/缺口 |
| `order.py` | 外盘下单、撤单、写库 |
| `market.py` | 行情/盘口订阅与查询 |
| `precision_exchange.py` | 外盘精度 |
| `deposit_withdraw_fee.py` | 充提相关仓位/费用采集 |

### `auto_wd/` 自动充提与划转
| 脚本 | 功能 |
|------|------|
| `wd.py` | 自动提币主逻辑（196→BN/Gate/Kraken；不足则从做市户补资） |
| `abc_api.py` | Websea 现货 API 封装 |
| `bn_api.py` / `gate_api.py` / `kraken_api.py` | 对应外盘 API |
| `196_to_bn.py` / `196_to_bn_withdraw.py` | 196 → Binance 提币（手工/脚本） |
| `bn_to_196_withdraw.py` | BN 对冲成交后按规则提回 196 |
| `gate_to_196_withdraw.py` | Gate 对冲成交后提回 196 |
| `maker_to_dc_transfer.py` | 做市户 → 17 → 196 内部划转 |
| `monitor_bn_gate_to_196.py` | 打印近 1h：196 充值 / BN·Gate 提币 |
| `test.py` | 指定账号资金划转测试 |

### `scripts/` 运维工具
| 脚本 | 功能 |
|------|------|
| `hedge_gap_summary.py` | 汇总/同步 hedge gap 表 |
| `hedge_gap_backup.py` | gap 表备份 |
| `gate_gap_depth_quote.py` | 按缺口表估 Gate 卖一挂单金额 |
| `run_binance_wallet_and_open_orders.py` | 查 BN 余额与挂单 |
| `run_gate_wallet_and_open_orders.py` | 查 Gate 余额与挂单 |
| `alter_abc_asset_gap_all_index_bigint.py` | 一次性改库字段类型 |

### `exchanges/`
| 目录 | 功能 |
|------|------|
| `restful_api/*.py` | BN/Gate/OKX/Huobi/MEXC/Bitget/Kraken REST |
| `spot_ws/*.py` | 深度、订单、钱包等 WebSocket |

### 其它
| 路径 | 功能 |
|------|------|
| `many_configs/` | 账户、交易所、共享内存等配置 |
| `libs/` | 工具、心跳、TG、告警 |
| `scaffold/` | MySQL/Redis/Mongo/aiohttp 脚手架 |
| `test.py` | 根目录一次性改库脚本（同 alter 脚本） |
| `README.md` | DEX/路由对冲配置说明（非脚本索引） |
