`sky_monitor` ，按用途梳理如下：

这个项目下，全部都是独立脚本，用来查询、测试、处理扎帐等各种事项
每次需要手动执行对应功能的脚本

### 下架与 Redis 清理
| 脚本 | 功能 |
|------|------|
| `spot_down_symbol_cancel_orders.py` | 下架币对：多做市账户批量撤单 |
| `spot_down_symbol_del_redis.py` | 下架币对：删 Redis 价格/心跳 key |
| `read_redis.py` | 读/删指定交易对 Redis（含心跳 field） |
| `update_redis.py` | 查/改 Redis 价差、刷量倍数等配置 |
| `abcapi_plus.py` | 精简 Websea API，供撤单脚本用 |

### 盈亏 / 成交统计
| 脚本 | 功能 |
|------|------|
| `count_spot_profit.py` | Mongo `real_deal`：用户已实现盈亏合计 |
| `select_mongoorder_table.py` | `mongoorders`：按交易对算已实现盈亏 |
| `select_mongoorder_table2.py` | `mongoorders`：逐笔打印并汇总买卖金额 |
| `select_inside_deal_amt.py` | `mongoorders`：买卖净成交额（USDT） |
| `select_outside_deal_amt.py` | `hedge.orders`：外盘对冲净成交额 |
| `count_bn_gate_history_deals.py` | BN+Gate 账户历史成交净额 |
| `unhedge_profit.py` / `spot_hedge_cost.py` | 内盘均价 vs BN/Gate 现价算跟单盈亏（口径相近） |
| `select_mongoorders_all_symbols_month_deal.py` | 按月按 symbol 汇总 buy/sell |
| `select_trades_all_symbols_month_deal.py` | `hedge.trades` 按月汇总成交与手续费 |
| `select_trades_table.py` | `hedge.trades` 按币种汇总 amount |
| `check_mongoorders.py` | 指定 symbol/时间成交汇总核对 |
| `spot_down_check.py` | 查近月交易对成交额/人数/笔数（SQL 探查） |

### 充提 / 钱包 / 资金
| 脚本 | 功能 |
|------|------|
| `select_deposit_history.py` | 查 BN 充值/提现历史 |
| `deposit_fee_count.py` | 统计 BN 近 N 月提币手续费 |
| `gate_withdraw.py` | Gate 余额提回 Websea 196 |
| `test.py` | BN 提币到 196 + 查余额（调试） |
| `select_spot_wallet.py` | 查 Websea / Gate / BN 现货资产 |
| `196_transfer_monitor.py` | 监控 196：提现是否有等额充值到账 |
| `buy_spot.py` | 外盘按固定 USDT 批量限价买入 |

### 扎帐 / 缺口
| 脚本 | 功能 |
|------|------|
| `扎帐自动调整.py` | 两时点 `dc当前值` 差 → 更新 `CORRECT_AMOUNT` |
| `dc_diff.py` | 算 `dc当前值` 差并与校正量合并输出 |
| `hedge_gap_summary.py` | 汇总/同步三张 gap 表（含 sync-fee） |
| `check_hedge_table.py` | 查 `hedge` 表结构与样例数据 |
| `load_mysql.py` / `update_mysql.py` | MySQL 临时查询/改数 |

### 其它
| 脚本 | 功能 |
|------|------|
| `find.py` | 目录下搜 `.py` 含某字符串 |
| `create_mysql.py` | 连合约库建表/迁数据类操作（临时） |
| `test2.py` | 查 Mongo `real_deal` 成交明细 |
