`abclibs` 不是业务进程，而是**全现货工程共享的远程配置库**（通常经 `load_remote` 被 `trade` / `monitor` / `spot_market_maker` 等拉取）。仅 5 个脚本：

| 脚本 | 功能 |
|------|------|
| `config.py` | 核心配置：外盘开关、价格权重、现货/合约对标（`PRICE_SYMBOL_CONFIG` 等）、`SPOT_CURRENCY_CONFIG` / `CONTRACT_CURRENCY_CONFIG`（危险等级、刷量所、做市量、价差、自刷、上线时间）、分区交易对派生、Redis 连接与价格有效期、环境 `DEBUG`/`launch_env` |
| `account.py` | API 账户：线上 `account`、测试 `account_test`（刷量/做市 near·defense·depth、dc/196、备份户等）；另有外盘对冲账户配置 |
| `price_async.py` | **异步**读 Redis：加权现货价、买卖一、档位价、合约价/偏移、精度；写价格/盘口/心跳相关接口 |
| `price.py` | 同上能力的**同步**版（`redis` 客户端），供非 async 代码用 |
| `dex_config.py` | DEX 配置：Uniswap/Sushi/Pancake 等池子地址与小数位；ETH/BSC/HECO/Polygon 节点池 |
