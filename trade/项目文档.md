`trade` 是现货/合约**刷量 + 价格指数 + 开盘/运维**工程。各脚本功能如下：

定时任务：
0 10 * * * echo "" | tee /home/ubuntu/code/trade/StartScripts/log/*.log

### 启动入口（`StartScripts/`）
| 脚本 | 功能 |
|------|------|
| `start_spot_price.sh` | 启现货成交价写入 Redis |
| `start_spot_ask_bid_n_ws.sh` | 启外盘买卖一/深度 WS |
| `start_spot_dex_price.sh` | 启 DEX 价格服务 |
| `start_volume.sh` / `start_volume_btc.sh` | 启现货刷量（分区） |
| `start_volume_ws_source.sh` | 启刷量外盘 K 线/量源 |
| `start_contract_ask_bid_n_ws.sh` | 启合约外盘买卖一 |
| `start_contract_price_from_abc.sh` | 启合约指数价（旧方案） |
| `start_contract_close.sh` | 启合约平仓服务 |

---

### 价格服务
| 脚本 | 功能 |
|------|------|
| `launcher_spot_price_server/spot_price.py` | 外盘成交价聚合 → Redis（做市/刷量用） |
| `launcher_spot_price_server/spot_ask_bid_center.py` | 外盘买卖一/深度 WS 中心 |
| `launcher_dex_server/price_dex_server.py` | DEX（Uniswap 等）链上价格 |
| `launcher_contract/contract_price_from_contract_ask_bid.py` | 合约价：外盘合约盘口加权写 Redis |
| `launcher_contract/contract_price_from_abc.py` | 合约价：订阅 Websea 指数（已较少用） |
| `price_repairman.py` / `price_repairman_contract.py` | 外盘停机时清理/校验 Redis 价格 |
| `ws_libs/ws_ask_bid_center.py` | 各所现货深度/买卖一 WS 实现 |
| `ws_libs/ws_contract_ask_bid.py` | 合约买卖一 WS |
| `ws_libs/price_libs.py` / `price_libs_swap.py` | 价格聚合与 DEX 拉取 |
| `ws_libs/funding_rate.py` | 外盘资金费率拉取 |

### 刷量服务
| 脚本 | 功能 |
|------|------|
| `launcher_volume_maker/volume_maker_center.py` | 主刷量：跟外盘量对 Websea 现货/合约下单 |
| `launcher_volume_maker/volume_maker_ws_source.py` | 订阅外盘量/K 线进共享内存 |
| `launcher_volume_maker/volume_maker_self.py` | 自刷（无外盘对标）现货/合约 |

| `ws_libs/volume_trade_add.py` | 现货刷量下单/撤单核心逻辑 |
| `ws_libs/volume_trade_add_contract.py` | 合约刷量下单逻辑 |
| `ws_libs/ws_volume_market_kline.py` / `ws_volume_market_price.py` | 外盘成交量/价格源 |
