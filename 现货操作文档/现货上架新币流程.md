现货上架新币流程

第一步: 填写config
服务器位置 server@10.0.209.181 /home/server/abclibs
在10.0.209.181服务器,登录server用户,到/home/server/abclibs目录下的config.py文件中添加2个内容:
  1. PRICE_SYMBOL_CONFIG = {
    f"BTC-{quote_currency}": {
        "price_symbol": {ExchangeCode.bn.value: "BTC-USDT"}, # 成交价格，DB1
        "depth_price": {ExchangeCode.okex.value: "BTC-USDT"}, # 买卖一价格中间价格 DB1
        "dex_price": {}
        },
    }
    # 同时会保存price_symbol & depth_price 买卖一，用来计算我们做市的买卖一 
    # ask1 = max(ask_list) bid1 = min(bid_list)
    # db 4 保存对标盘口前N档的数据，用来对标前N档的数据

  2. SPOT_CURRENCY_CONFIG = {
        "BTC": {
            "dangerous_level": 1,  # 1 等级越小的危险系数越小
            "hedge_threshold": "threshold_1",  # 对冲阈值级别
            "use_account": "1",  # 使用哪个账号
            "exchange": [(ExchangeCode.bn.value, "BTC-USDT",), (ExchangeCode.okex.value, "BTC-USDT",)],  # 刷量对标顺序
            "mean_order_size": {"BTC-USDT": 0.021},  # 做市档位量配置   这里填写币的数量,大约是1000-2000U就可以
            "ask_bid_percent_spec": {"BTC-USDT": 0.00001, "BTC-USDT_PRICE": 0.1},  # 买卖一价差配置，支持价格或者价差配置
            "zone": ["USDT"],  # 现货所有上线的zone
            "self_zone": ["USDT"],  # 现货自刷量开启的zone
            "self": 2,  # 0 不启用 1 主力刷量 2 非主力刷量
            "self_market_value": 500,  # 自每次自刷量价值u
            "open_time": "2021-8-9 14:02:55"
        },
    }

第二步: 重启服务和策略
    服务器 ubuntu@10.0.209.181 | /home/ubuntu/code/trade 目录
    1. 现货市场价格 StartScripts/start_spot_price.sh
    2. 现货买卖N档价格 StartScripts/start_spot_ask_bid_n_ws.sh
      前2个是重启服务,并且tg群会报警,需要研发也重启服务
      看日志检查是否有报错
    3. 刷量-成交量数据源 StartScripts/start_volume_ws_source.sh
      重启后需要等待20s以上,再重启第四个文件
    4. 刷量-成交量逻辑 StartScripts/start_volume.sh
    5. 开盘脚本： /home/ubuntu/code/trade/new_online.py
      记得修改脚本中symbol和price的值
      这个脚本一定要在过了整点后启动,为了防止做市策略因拿不到价格而持续不下单,则先启动new_online.py再重启做市脚本
    6. 重启做市脚本
    服务器 ubuntu@10.0.208.182 ubuntu@10.0.209.47 | /home/ubuntu/code/spot_market_maker 目录
    启动程序: sh restart.sh
    7. 重启监控脚本
    python manage_quant.py restart


后台添加对冲配置：
    对冲阈值:10000 币的数量，可以写的高一点
    对冲阈值价值(USDT): 实际触发对冲下单的金额,最低5-10U,高的差不多500U
    对冲出口(USDT):看外盘盘口前三档金额配置,要比上一行高
    权重是1
    对冲方向：both
    状态：打开选择正常
    最后一个选择不变
